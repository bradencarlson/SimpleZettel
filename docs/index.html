Zk CLI Documentation

Zk is a command line tool for managing a personal knowledge base (a zettelkasten). You can create boxes, add Markdown notes to boxes, and import files into boxes to keep track of other information such as scholarly articles.

Zk was designed with numbering of notes in mind. It is the user's responsibility to name their notes in such a way that they are able to find them to recall information quickly, and Zk will assist the user in doing this by sorting notes according to the following scheme:

  • There are three types of note names:
    1. Numeric: any note name matching the regular expression ^[0-9]+(\.[0-9]+)*$. For example 1, 1.23.2, or 32.2.11.9.4.
    2. Alphanumeric: any sequence of valid UTF-8 characters not falling into the numeric category.
    3. Invalid names: a sequence of characters which cannot be represented as a UTF-8 string.
  • Numeric notes come before alphanumeric notes, which come before notes with invalid names. Numeric notes are ordered according to the digits that appear before each period. For example
    1.2 < 1.3 < 1.3.1 < 2.3 < 2.4
  • Alphanumeric notes are sorted in alphabetical order.
  • Notes with invalid names are displayed in a random order.

With the above ordering in mind, it is recommended to name notes according to a Luhmann style system (i.e. the note whose name is 1.3.4.2 is related to note 1.3.4, but does not follow the same line of thought as note 1.3.4.1).
