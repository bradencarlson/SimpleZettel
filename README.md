#  SimpleZettel

SimpleZettel is a command line tool for managing a personal knowledge base (a
zettelkasten). You can create boxes, add Markdown notes to boxes, and
import files into boxes to keep track of other
information such as scholarly articles. As an example, here is what the output
of `szettel` might look like after taking some notes on the Rust programming
language:
![](./docs/img/rust-zk.svg)

[documentation]().
