# Zk 

Zk is a command line tool for managing a personal knowledge base (a
zettelkasten). You can create boxes, add Markdown notes to boxes, and
import files into boxes to keep track of other
information such as scholarly articles. The following short video showcases the
main features of zk:
![](./docs/img/demo.mkv)
